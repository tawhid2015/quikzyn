2. Description of Service

Message Alarm – Notification Alerts is a mobile application for Android devices that allows users to create custom alarm rules based on notification content. The App monitors incoming notifications from user-selected applications and triggers an audible alarm when specific keywords or phrases are detected in the notification text.

Key features of the App include:

  • Creating alarm rules with custom keywords for specific applications
  • Customizable alarm sounds, including system tones and user-provided audio files
  • Ability to override Do Not Disturb and Silent mode settings
  • Scheduling alarm activity based on specific hours and days
  • On-device notification processing with no data transmission to external servers
